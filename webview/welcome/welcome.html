How to Open

Click the button shown below or use Ctrl+Shift+P and search for Dota2 Icons to open the icon picker

Usage

Click an icon to copy its name for use in KV files. Right-click to browse the source file (do not modify files in that folder). Search supports space-separated terms and regex. Use the hero portrait on the left to filter by hero.

Notes

If the extension correctly detects the game and content directories, custom icons from your project will appear after the official icons. See Project Setup for directory configuration.

How to Open

Click the button shown below or use Ctrl+Shift+P and search for Dota2 Cosmetics Browser to open the window

Usage

When configuring cosmetics for a unit, you typically need to unpack items_game.txt to find the cosmetic ID, or use the DOTAUIEconSetPreview UI tag which requires courier cosmetic IDs. Paste the model path into the search box to get the relevant info.

1. Copy the cosmetic model path

2. Paste into the search box

Tip for searching sets: first search for a single cosmetic item, then copy the set ID to search.

Searching a hero name directly will show all cosmetics for that hero (currently only supports internal hero names).

How to Open

Click the button shown below or use Ctrl+Shift+P and search for vsnd picker to open the selector

Usage

Find the desired sound file in the Dota 2 resource browser, copy its path and paste it into the search box. The selected sound will be automatically inserted at the cursor position in the current text editor.

How to Open

Find the book-like icon on the left sidebar.

How to Use

Click a function in the tree view to see its details.

Click a class in the list to view all its functions.

Click edit to modify its info, including description, parameter types/names/descriptions, return values, examples, etc.

Lua API changelog — view API changes across different periods.

Other features like Search and Favorites can be explored on your own.

Notes

  • Currently the note editing feature only supports Lua and CSS. Changes are stored in the database — please be careful when editing others' contributions. You can correct errors though.
  • Do not use line breaks in the description field of note editing — they conflict with other content and will be automatically removed before upload.
  • If you use the extension's Lua code completion, notes will also update in the completion hints.
  • If you use a Lua parser plugin like EmmyLua, you can use the command Generate EmmyLua API docs to generate a definition file in your project. Each generation uses the latest notes.
  • Documents you don't want to see can be disabled in settings.

Why Configure the Project

As you may know, a Dota 2 project has separate game and content directories in different folders. For better project management (e.g., using Git for version control), it is convenient to have both folders under one directory. This extension also provides better support for a correctly configured project.

How to Configure the Project

Method 1

Use symbolic links (symlinks). See this guide or search for the mklink command.

Method 2

Use the software Link Shell Extension (download link at the bottom of the page; install the prerequisite package if it doesn't run — the link is next to the download).

First, create a folder at your preferred location for the project.

Then go to the Dota 2 game directory, right-click your project folder, and select "Pick Link Source".

Go back to the game directory you just created, right-click, and select "Drop As Junction".

Repeat the same steps for the content directory to get a folder with both game and content.

Notes

If you don't want to set up the project structure (e.g., you don't use version control and simply added both folders to a VS Code workspace), you can manually configure the game and content paths in Settings under Addon_path. It's best to set this in workspace settings.
